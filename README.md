#virtual assistant## 🧠 My Virtual Assistant (Voice-Activated)

🚀 **Live Demo**: [Click to View](https://amarsin22.github.io/My-Vitual-Assistant/)

---

### 📌 Description:

**My Virtual Assistant** is a simple voice-activated assistant built using **JavaScript and Web Speech API**. It listens to your voice commands and performs basic tasks such as greeting you, telling the time/date, opening websites, and answering simple questions.

This project showcases how speech recognition and speech synthesis can be implemented in the browser using JavaScript, making it a beginner-friendly introduction to voice technology.

---

### 🗣️ Key Features:

- 🎤 Voice recognition using **Web Speech API**
- 🧏‍♂️ Speech response using **Speech Synthesis**
- ⏰ Responds with current time and date
- 🌐 Opens websites like Google, YouTube, Facebook, etc.
- 🧠 Understands basic conversation (e.g., “How are you?”)
- ⚡ Lightweight, fast, and interactive

---

### 💻 Technologies Used:

- 🧱 **HTML5** – Page structure  
- 🎨 **CSS3** – User interface styling  
- ⚙️ **JavaScript** – Core voice logic and event handling  
- 🗣️ **Web Speech API** – Voice recognition and speech output

---

### 🎯 How to Use:

1. Click the microphone 🎤 button on the screen  
2. Speak your command (example: _“What’s the time?”_, _“Open Google”_, _“How are you?”_)  
3. The assistant will listen, process, and respond via voice
